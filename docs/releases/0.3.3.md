# Hermes Mobile 0.3.3 (10) preview

Built 18 November 2026 from `24e53d3`. **Installed as an in-place update on the owner's Pixel at 14:06 Sydney on 18 November 2026.** Phone behavior acceptance remains open.

## Changes

One-tap full-screen hands-free entry with animated listening, processing, speaking and paused states; protected End/Back; image/camera access; and a new-conversation action inside voice. Normal chat keeps image attachment, text entry and an icon-only voice action. Typed-reply readback and optional content-free response timings move to settings. Voice replies speak independently of the typed-readback preference.

Creation and voice entry are fenced by navigation revision, endpoint epoch and ownership, so delayed callbacks cannot activate a room after navigation. Selected voice images remain backed by the existing durable draft and do not automatically consume unrelated typed attachments. Playback and capture share serialized audio-mode changes and capture cleanup barriers. The complete-file STT, canonical prompt and exact-final-reply TTS path remains; native duplex voice is not enabled.

## Short owner checklist

1. Start Tailscale on the phone and confirm Hermes connects; check existing chats, drafts, attachments and settings.
2. Tap the waveform once. Speak, hear the reply, interrupt by tapping the speaking orb, then test Pause/Resume and protected End/Back.
3. Add a photo and use the camera inside hands-free. Check review, remove and Send; verify unrelated typed drafts stay intact.
4. Start a new conversation inside hands-free. Check the old chat/draft remains and the new room starts once. Background/lock the phone and confirm it returns paused.
5. Check quiet/background-noise behavior, Bluetooth/calls, reduced motion, large text and TalkBack as applicable.

These native interactions, acoustic behavior and performance remain owner acceptance. Installation success alone does not establish them. For a problem, End voice and continue in normal text chat; do not clear app data or blindly install an older APK.
